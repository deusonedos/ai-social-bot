# AI Social Bot

AI-помощник, которого зовут прямо в чат. Понимает текст и изображения, отвечает текстом.
Работает на бесплатных моделях OpenRouter.

Архитектура и обоснование решений — в [TECH_DESIGN.md](TECH_DESIGN.md).
Продуктовая идея — в [AI_Social_Bot_Project.md](AI_Social_Bot_Project.md).

## Что уже умеет

- Личные чаты и группы Telegram
- Текстовые вопросы
- Фото: решить пример, распознать текст, объяснить схему, законспектировать
- Память диалога с изоляцией по чатам (и по топикам в супергруппах)
- Автоматическое сворачивание длинной истории в сводку
- Фолбэк между моделями, circuit breaker, учёт суточной квоты
- Рейт-лимиты на пользователя и на чат

Голосовые пока не подключены — под них есть задел (см. ниже).

## Запуск

Нужен Node.js 20+ и любой Postgres (локальный, Supabase, Neon).

```bash
npm install
cp .env.example .env
```

Заполни в `.env` три обязательных значения:

- `TELEGRAM_BOT_TOKEN` — у [@BotFather](https://t.me/BotFather), команда `/newbot`
- `OPENROUTER_API_KEY` — на [openrouter.ai/keys](https://openrouter.ai/keys)
- `DATABASE_URL` — строка подключения к Postgres (для Supabase/Neon ещё `DATABASE_SSL=true`)

Затем:

```bash
npm run dev
```

Схема БД применяется автоматически при старте. В dev-режиме бот работает через long
polling — туннель не нужен.

## Настройка бота в BotFather

**Privacy mode оставь включённым** (это значение по умолчанию, ничего делать не надо).
Тогда в группах бот видит только упоминания, реплаи на себя и команды — права
администратора ему не нужны, а поток апдейтов меньше на порядки.

Полезно задать через `/setcommands`:

```
help - что я умею
reset - забыть историю этого чата
```

## Как бот понимает, что обращаются к нему

| Ситуация | Реакция |
|---|---|
| Личный чат | отвечает всегда |
| `@бот вопрос` в группе | отвечает |
| Reply на сообщение бота | отвечает |
| Фото с подписью `@бот реши` | разбирает фото |
| Reply на чужое фото с текстом `@бот реши` | разбирает то фото |
| Всё остальное в группе | молчит |

**Фото без подписи в группе бот не увидит** — при privacy mode такие сообщения до него
не доходят. Это не баг, а осознанный размен: взамен не нужны админ-права. Рабочий путь —
ответить на фото сообщением с упоминанием.

## Команды

```bash
npm run dev            # разработка с автоперезапуском
npm test               # быстрые проверки логики (без токенов и БД)
npm run typecheck      # проверка типов
npm run models:check   # сверить модели с живым каталогом OpenRouter
npm run build && npm start
```

### `npm run models:check` — запускай регулярно

Бесплатный список моделей на OpenRouter меняется часто: модель может исчезнуть или
перестать быть бесплатной в любой день. Скрипт сверяет `src/config/models.ts` с живым
каталогом и проверяет не только цену, но и модальности — иначе в цепочку однажды попадёт
модель с нулевой ценой в полях API, но с аудио на выходе вместо текста.

## Про лимиты и деньги

Бесплатный тир OpenRouter ограничен **числом запросов на весь аккаунт**: 20 в минуту и
1000 в сутки (50, если аккаунт ни разу не пополнялся). Это потолок примерно на 30–50
активных групп.

При исчерпании квоты бот вежливо отказывает. Если включить `PAID_OVERFLOW_ENABLED=true`,
он вместо этого уйдёт на дешёвые платные модели — порядка **$1–2 за 10 000 ответов**.

## Структура

```
src/
├── config/     env (zod) и реестр моделей — единственное место с их именами
├── ai/         шлюз OpenRouter, роутер с фолбэком, сборка контекста, промпты
├── core/       пайплайн, очередь, рейт-лимиты, общие типы
├── db/         схема и запросы
├── bot/
│   └── telegram/   триггеры, медиа, форматирование ответа
└── util/
scripts/        проверка моделей и смоук-тесты
```

Пайплайн (`src/core/pipeline.ts`) не знает про Telegram — адаптер приводит события
к общим типам и доставляет ответ. Threads и Instagram добавляются как новые адаптеры,
без изменений в ядре.

## Задел под голосовые

Всё готово, кроме перекодирования и обработчика:

- Модели с нативным audio input уже прописаны в `src/config/models.ts` (роль `audio`) —
  отдельный Whisper не нужен
- `Attachment` в `src/core/types.ts` уже поддерживает `kind: 'audio'`
- `collectAudio()` в `src/bot/telegram/media.ts` — заглушка с описанием, что доделать

Останется: скачать `msg.voice`, перегнать ffmpeg-ом из ogg/opus в mp3, получить
расшифровку и прогнать её обычным текстовым путём, чтобы история осталась текстовой.

Учти: у голосовых в Telegram не бывает подписи, поэтому в группах их можно поймать
только через reply.
